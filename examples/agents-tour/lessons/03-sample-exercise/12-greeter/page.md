**Your turn.** Let's make our `greeter` agent wait for the first message and return `Hello, ` followed by the content of the message and `!`.

Press {Run}. Run calls the code in `run.ts`, which starts our `greeter` agent with the message `Ada`. In the Trace, the run of our `greeter` agent shows what our `greeter` agent returned.

Press {Check} when you think our `greeter` agent works. Check sends `Ada` to our `greeter` agent and looks at what the run returned.
