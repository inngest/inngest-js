**Your turn.** Let's make our `greeter` agent wait for the first message and return `Hello, ` followed by the content of the message and `!`.

Press {Run}. Run calls the code in `run.ts`, which starts `greeter` with the message `Ada`. In the Trace, the run shows what `greeter` returned.

Press {Check} when you think `greeter` works. Check sends `Ada` to `greeter` and looks at what the run returned.
