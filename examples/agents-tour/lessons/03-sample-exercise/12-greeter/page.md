# Greeter

**Your turn.** Make `greeter` wait for its first message and return `Hello, ` followed by the message's content and `!`.

Press {Run}. Run calls the code in `run.ts`, which starts `greeter` with the message `Ada`. In the Trace, the run of `greeter` shows what `greeter` returned.

Press {Check} when you think `greeter` works. Check sends `Ada` to `greeter` and looks at what the run returned.
