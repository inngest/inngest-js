# Hello, agent

An agent is a function that Inngest runs for you, durably. The smallest agent has an `id` and nothing else.

Press {Run}. Run calls the code in `run.ts`, which starts `hello` with the message `Hi`.

In the Trace, the run of `hello` is completed. The first row of the run is the message `Hi`. `hello` has no body yet, so the run returns nothing.
