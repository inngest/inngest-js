# The controls

**Run** starts your code. **Reset** puts the page's code back and restarts the Dev Server, so the runs list is empty again.

**Format** tidies the code. **Next** and **Previous** change page.

Every button shows its key. On pages with code the editor has focus, so the keys that work there use a modifier: <kbd>Ctrl</kbd>+<kbd>Enter</kbd> runs the code.

Press <kbd>Alt</kbd>+<kbd>/</kbd> to see all of them.

*Note:* <kbd>Tab</kbd> indents inside the editor. <kbd>Ctrl</kbd>+<kbd>M</kbd> makes it move focus instead.
