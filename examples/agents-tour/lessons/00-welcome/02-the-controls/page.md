# The controls

**Run** starts your code. **Reset** puts the page's code back the way it was.

**Format** tidies the code. **Next** and **Previous** change page.

Every button shows its key. The editor has focus when a page opens, so the keys that work there use a modifier: <kbd>Ctrl</kbd>+<kbd>Enter</kbd> runs the code.

Press <kbd>Alt</kbd>+<kbd>/</kbd> to see all of them.

*Note:* <kbd>Tab</kbd> indents inside the editor. <kbd>Ctrl</kbd>+<kbd>M</kbd> makes it move focus instead.
