# Sound design prototype (throwaway)

A prototype for the Agents Tour's optional sound. Not part of the tour build.

Open `index.html` by double-clicking it. Nothing plays until you click the speaker (or press `M`). Every sound is synthesised with the Web Audio API; there are no audio files.

The speaker is a plain on/off button (`M`); hover it, or press `Shift+M` or ArrowDown on it, for the style menu (`Esc` closes it). Other keys are shown on the buttons.
