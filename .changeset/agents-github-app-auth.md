Experimental agents: `githubApp({ appId, privateKey })` authenticates as a GitHub App for the commits, pushes and pull requests an agent makes, so the App and not a person is their author. It signs the App's JWT with WebCrypto (no Node-only imports, so it runs on Workers too; a PKCS#1 key as GitHub issues it, a PKCS#8 key and a PEM with `\n` written out are all read), finds the installation of a repository, organization or user, and mints installation tokens that can be narrowed to repositories and permissions (a token for `owner/name` is narrowed to that repository unless you pass `repositories: "all"`). Tokens are cached until five minutes before they expire, an installation that was removed and made again is found again, and the same ask made at once is made once. `app.installedRepos()` lists the repositories of all non-suspended installations. An App that is not installed on a repository is a `GithubAppNotInstalledError`, the one failure to answer with a fallback token; any other failure is a `GithubAppError` with the status. Use it where a token is wanted, such as `repo({ token: () => app.token("acme/app") })` and `sandbox.tools.git({ token: () => app.token("acme/app") })`.
